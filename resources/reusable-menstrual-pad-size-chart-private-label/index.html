Private-label buyer guide

Reusable Menstrual Pad Size Chart for Private Label Buyers

Turn a reference photo into a size chart your supplier can measure, your team can approve, and an inspector can use on finished pads.

Prepared by ReuseCareNovember 18, 2026
View the measurement table ↓

Mark the points you want measured

Start with a photo to identify the outline, wing shape and closure placement you want to discuss. Ask the supplier for a dimensioned drawing or an annotated sample photo with arrows and named endpoints. Assign a style code to each outline and carry those same labels into the quote, drawing and sample record. A photo without a scale and a defined measurement method is an appearance reference only.

Agree on units and measure the finished sewn pad flat, relaxed and unstretched unless the field calls for the snaps to be closed. Mark where each width is taken and whether the reference edge is the outer finished edge or a seam. Use the same setup for each sample so changes in the readings can be traced to the pad.

Measurement and sample confirmation table

Use one copy per style. Record the target, actual reading and approval status for each field, with the drawing revision beside the sample ID.

FieldMeasurement methodSample confirmation
Finished lengthMeasure in a straight line along the centerline from the front finished edge to the back finished edge.Mark front and back and record the measured length.
Body width, excluding wingsMeasure across the finished body at the marked point, perpendicular to the centerline. Add front or rear widths if coverage depends on them.Record each width with its location on the drawing.
Open wing spanLay both wings flat and measure straight across between the marked outer wing tips.Check tip positions and record the open span.
Fastened fit widthClose the wings around the agreed underwear gusset or fit template. Record the reference gusset width at the closure line for each snap setting reviewed.Record the setting and check for secure closure, bunching and unwanted slack on that reference.
Absorbent area lengthMeasure between the front and back boundaries of the absorbent core along the centerline. Use the construction drawing and a marked or opened reference sample if the core is hidden.Confirm core endpoints and length for the identified build.
Post-wash dimensionsMeasure the agreed fields before washing and again after the agreed wash and dry routine, using the same points and setup.Log cycle count, wash and dry conditions, before and after readings, and any fit change on the same reference.

Give day, night and absorbency their own fields

Use day and night to describe wear context. For each style, specify the coverage and fit you want and record the actual dimensions separately. An overnight brief may call for more rear coverage, which can require a different outline even when the center width stays the same. A longer pad or core does not establish an absorbency volume. If your brand needs a performance claim, agree on a finished-pad test method and acceptance criteria for that exact construction. See the day and night variant guide for wear and coverage decisions.

Define the starter set by style and pack count

Give the set its own SKU and list the pad style code, revision and piece count for each component. State the total pads per retail pack, any included accessories, the packaging format and whether your order quantities refer to individual pads or packed sets. The three pads shown in the photo help explain the presentation. Confirm the actual assortment and count on the pack specification and review a packed sample against that list.

Approve the measured sample and its tolerances

Label each physical sample with its style code, sample ID and revision. Attach the measurement sheet, wash record and fit reference to the approval. Set dimensional tolerances field by field from the approved sample and the buyer's requirements. Confirm which limits apply before and after washing and have both parties approve the inspection method. If a revision changes the pattern or snaps, recheck the affected fields and record which sample supersedes the earlier one. Follow the sample approval workflow to keep the sign-off traceable.

Send a quote request the supplier can answer

  • Attach reference images and a marked drawing for each style, noting which dimensions are targets and which need a supplier proposal.
  • List intended use, closure settings, fit reference, wash protocol and any separate absorbency requirement by style.
  • Give quantities by pad style and packed SKU, the exact assortment per retail unit, packaging and artwork needs, and destination.
  • Ask for proposed drawings, identified samples, a completed measurement sheet and a list of open decisions before sign-off.
