Material and artwork guide

Custom Printing Quality Checks

Seven decisions to record before printed fabric is cut for reusable hygiene products.

Prepared by ReuseCareUpdated September 29, 20267 minute read
Buyer takeaway

Approving a small artwork file is not the same as approving printed fabric. Record the scale, repeat, direction, color reference, base material and acceptable result on a physical sample.

Why print approval needs its own brief

A print can look correct on a screen and still create problems on a finished product. The motif may be too large for a nursing pad, face the wrong direction on a bib, or place key elements under seams and snaps. Printed PUL and other reusable textile materials also need to be reviewed together with the selected base fabric and intended product.

Artwork file and ownership

Start with the original artwork, not a screenshot. Confirm the file format, dimensions, color mode, repeat structure and whether the buyer has permission to use every element. If a supplier adjusts the repeat or cleans the file, the revised production artwork should be returned for approval.

Print scale and repeat

State the intended motif size in a physical unit such as centimetres. A PDF preview should include a scale reference. For products with small cutting pieces, ask for a mock-up showing how the repeat will appear inside the actual pattern shape.

Direction and placement

Directional artwork needs a clear top and bottom. The cutting plan should also define whether pieces may rotate to improve material use. If a logo or character must appear in a specific area, treat it as a placement print and record the permitted position rather than leaving it to chance.

Color reference and viewing conditions

Screen colors vary. Use a physical color standard or an approved printed swatch when color accuracy matters. Review the swatch under consistent light and record which side of the material is being judged. A second approval may be needed when the same design is printed on a different base material.

Base material and performance

The artwork approval should identify the material construction, width and weight. For PUL applications, buyers should separately confirm waterproof-layer requirements, care instructions and any product-specific test plan. A visual print approval does not prove waterproof performance or regulatory compliance.

Seven points to approve before cutting

Original fileCorrect format, resolution and usage rights.
RepeatConfirmed repeat dimensions and join behavior.
ScaleMotif size shown in centimetres on the sample.
DirectionTop, bottom and permitted pattern rotation.
ColorPhysical reference and viewing conditions.
Base materialComposition, width, weight and surface.
Product mock-upExpected appearance inside the cutting pattern.

What to ask for with the production sample

  • A labeled swatch showing the approved artwork version and material.
  • A finished sample showing print direction across all visible pieces.
  • Confirmation of print scale and any placement tolerance.
  • A note explaining how color variation between lots will be handled.
  • Separate test evidence for any claimed material performance.
